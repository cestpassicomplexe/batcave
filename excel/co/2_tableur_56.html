Formatage personnalisé de données

Vous pouvez également avoir envie de créer votre propre format en ajoutant par exemple l'unité utilisée à la suite d'une valeur numérique.

Lorsque nous choisissons le format de cellule personnalisé, nous avons une liste de type assez énigmatique :

  • 0

  • 0,00

  • #.##0

  • #.##0,00

  • #.##0;-#.##0

  • etc.

Non, ce n'est pas du chinois. Nous allons voir ce que cela représente : il s'agit en fait d'un format qui sera appliqué à la valeur présente dans la cellule.

Nous retrouvons 3 codes qui peuvent apparaître :

  • 0 : Affiche un chiffre et remplace par un 0 s'il manque un chiffre;

  • # : Affiche également un chiffre mais n'affiche rien s'il manque un chiffre ;

  • ? : Affiche la valeur sous forme de fraction.

Nous pouvons également associer ces codes ensemble : ##0 est tout à fait possible. Selon vous, qu'est-ce que cela va avoir comme impact sur l'affichage ?

Exemple :

29 avec le format personnalisé 000 affichera : 029

29 avec le format personnalisé ### affichera : 29

29 avec le format personnalisé ?/? affichera : 29/1

Ajouter du texte

Si vous souhaitez ajouter du texte, il vous faudra le placer entre guillemets double : "

Exemple : Prenons un exemple :

Nous souhaitons ajouter l'unité km dans un tableau de distances parcourues.

On peut facilement le réaliser en modifiant le format personnalisé.

  1. Sélectionner la ou les cellule(s) pour lesquelles on souhaite modifier le format

  2. Sélectionner la catégorie "Personnalisée"

  3. Nous souhaitons afficher des distances domiciles/travail, nous pouvons espérer que les valeurs encodées soient comprises entre 0 et 999 au maximum. Nous allons donc encoder le format ##0.

  4. Ajouter la mention "km" entre guillemets après la mention ##0

Créer une suite

Lorsque vous voulez compléter les espaces vides de votre cellule par une répétition de caractères, faites-le précéder du symbole *

Exemple :

*. va donner .....................

*_ va donner _______________

etc.

Formater une date

Comme vous le savez, une date est composée de 3 éléments ; le jour, le mois et l'année et il y a de nombreuses façons d'afficher une date selon l'élément que l'on souhaite mettre en évidence. Ci-dessous les codes à utiliser selon le format souhaité :

Le jour

  • j : affiche le nombre du jour de 1 à 31 ;

  • jj : affiche le nombre du jour de 01 à 31 ;

  • jjj : affiche les trois premières lettres du jour ;

  • jjjj : affiche le jour en toutes lettres.

Le mois

  • m : affiche le nombre du mois de 1 à 12 ;

  • mm : affiche le nombre du mois de 01 à 12 ;

  • mmm : affiche les trois premières lettre du mois ;

  • mmmm : affiche le nom du mois.

L'année

  • aa : année sur 2 chiffres ;

  • aaa : année sur 4 chiffres.

Formater une heure

Il faut savoir qu'un temps est traité par Excel comme une valeur décimale comprise entre 0 et 1.

Les codes permettant de formater ces données sont :

h: pour les heures

m: pour les minutes

s : pour les secondes

Exemple :

hh"-"mm"-"ss
